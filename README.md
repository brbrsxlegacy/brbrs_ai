# brbrs AI Pro

## Kurulum

```bash
npm install
```

`.env.example` dosyasını `.env` diye kopyala ve Groq API key yaz:

```env
OPENAI_API_KEY=gsk_xxxxxxxxx
```

Çalıştır:

```bash
npm start
```

Aç:

```txt
http://localhost:3000
```

## Render

Build Command:

```bash
npm install
```

Start Command:

```bash
npm start
```

Environment Variable:

```txt
OPENAI_API_KEY = gsk_xxxxxxxxx
```

Render linkinden direkt aç. `index.html` içinde `localhost` yok; `/chat` kullanıyor.
